## Pick a template

DeesseJS ships a curated registry of starter projects (web apps, mobile apps, edge functions, AI agents) that all share the same auth, database, email, and storage contracts. Pick one, scaffold it, run it.

```bash
npx deessejs@latest init <slug>
```

Replace `<slug>` with any template identifier from the [Templates](/docs/cli-commands#deessejs-list) list, or pass a GitHub repository URL. Both forms require a valid root `deesse-template.json`, which selects the files copied into the project. The CLI creates the project in `./<slug>` for catalog entries, detects your package manager from the lockfile or `packageManager` field, then installs dependencies.

## Requirements

- **Node.js 20.0.0 or newer**: the CLI's `engines` field enforces this. Older versions fail fast at install time.
- **GitHub access**: every `init` downloads the selected GitHub repository archive.
- **A package manager**: Choose `pnpm`, `npm`, `yarn`, or `bun`. The CLI selects one from the generated project's lockfile or `packageManager` field. Pass `--pm <name>` to choose a different manager.

Run `init` without an account. Sign in only to publish templates, leave reviews, or use features that call the DeesseJS API. See [CLI: Authentication](/docs/cli-auth).
