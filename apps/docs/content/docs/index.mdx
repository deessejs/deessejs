## Pick a template

DeesseJS ships a curated registry of starter projects — web apps, mobile apps, edge functions, AI agents — that all share the same auth, database, email, and storage contracts. Pick one, scaffold it, run it.

```bash
npx deessejs@latest init <slug>
```

Replace `<slug>` with any template identifier from the [Templates](/docs/cli-commands#deessejs-list) list. The CLI clones the template repo into `./<slug>`, detects your package manager from the lockfile or `packageManager` field, and installs dependencies.

## Requirements

- **Node.js 20.0.0 or newer** — the CLI's `engines` field enforces this. Anything older fails fast at install time.
- **Git** — every `init` clones a GitHub repo. `git` must be on `PATH`.
- **A package manager** — `pnpm`, `npm`, `yarn`, or `bun`. The CLI picks one based on the cloned repo's lockfile or `packageManager` field; pass `--pm <name>` to force.

No account is required for `init`. Authentication only matters if you want to publish templates, leave reviews, or use features that hit the DeesseJS API — see [CLI: Authentication](/docs/cli-auth).
