# 0.3.0 — Mobile and desktop templates, plugin system

Two new surfaces and the foundation for first-party plugins.

## Added

- `mobile` template: React Native + Expo with the same auth, billing, and contracts as the web stack.
- `desktop` template: Tauri shell wired to the same backend, with typed IPC across the contracts.
- Plugin manifest at `~/.config/deessejs/plugins/` — third parties can now publish their own template starters.
