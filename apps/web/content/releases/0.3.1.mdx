# 0.3.1 — CLI plugin loader, registry cache eviction

## Fixed

- Plugin loader no longer crashes when two plugins declare the same subcommand; the last one wins and a warning is logged.

## Deprecated

- The `deessejs registry.pull --force` flag is deprecated. Use `deessejs registry.refresh` instead; the old flag will be removed in 0.5.0.
