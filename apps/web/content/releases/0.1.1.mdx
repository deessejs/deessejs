# 0.1.1 — Auth fixes, billing webhook hardening

Patch release focused on stability and a few quality-of-life wins.

## Fixed

- Session refresh race condition that occasionally dropped users after a hot reload.
- Stripe webhook idempotency check now uses the event id, not the signature, so retries no longer double-charge.

## Changed

- `deessejs init` now prints the resolved template registry URL alongside the resolved install path.
- The `info` subcommand emits a non-zero exit code when contracts are out of sync.
