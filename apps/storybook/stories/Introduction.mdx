# DeesseJS UI

The public catalogue for the shared primitives in `packages/ui`.

Use the **Mode** toolbar to switch between the light and dark design tokens. Every shared UI component has a documented example under **Components**.

## Remote MCP

Connect an MCP client to `https://storybook.deessejs.com/api/mcp` to search and read component documentation. The endpoint exposes Storybook's documentation tools only. It does not expose test execution, browser control, or local filesystem access.
