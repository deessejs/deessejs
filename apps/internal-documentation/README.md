# @workspace/internal-documentation

Internal documentation site for the DeesseJS monorepo.
Built with [Next.js](https://nextjs.org) + [Fumadocs](https://fumadocs.dev).

## Scope

This site renders the engineering documentation as a
navigable web surface. The ADRs, rules, knowledge-base
entries, and process guides live as MDX files in
`content/docs/` and are read directly.

The site's content source is `content/docs/`. The source is
intentionally curated — this site is the rendering target
for content that benefits from a web treatment (onboarding,
process, culture). Code-adjacent reference content lives in
JSDoc and source comments.

## Development

```bash
pnpm dev          # dev server on http://localhost:3000
pnpm build        # production build
pnpm start        # serve the built app
pnpm lint         # eslint
pnpm format       # prettier
pnpm typecheck    # fumadocs-mdx + next typegen + tsc
```

## App layout

```
app/
  (home)/page.tsx     landing page
  docs/[[...slug]]/   documentation pages (Fumadocs MDX)
  og/docs/...          OpenGraph image generation
  llms.txt/            llms.txt index for LLM crawlers
  llms-full.txt/       full-text dump for LLM crawlers
  llms.mdx/docs/...    per-page MDX export for LLM consumers
  api/search/          search backend (Orama)
content/docs/          MDX source files (curated)
lib/
  source.ts            content source adapter
  shared.ts            shared route constants
  layout.shared.tsx    layout options
  cn.ts                Tailwind class-name helper
```

## Conventions

This app follows the DeesseJS monorepo conventions:

- **Workspace package name**: `@workspace/internal-documentation`.
- **Dependencies**: pinned to the workspace catalog (no
  hardcoded versions for `next`, `react`, `lucide-react`, etc.).
- **TypeScript**: extends `@workspace/typescript-config/nextjs.json`.
- **ESLint**: extends `@workspace/eslint-config/next`.
- **MDX generation**: ignored by lint (auto-generated by
  `fumadocs-mdx`).
