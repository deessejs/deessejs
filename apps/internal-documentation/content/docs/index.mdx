## What is elsewhere

The authoritative documentation lives in the monorepo:

- **ADRs** — `docs/engineering/architecture/decisions/`
  capture architecture-level decisions (oRPC is load-bearing,
  package structure, consumer-agnostic API, etc.).
- **Rules** — `docs/engineering/architecture/rules/` are
  the standing, always-on constraints every PR must respect.
- **Knowledge base** — `docs/engineering/architecture/knowledge-base/`
  documents how external libraries (better-auth, Hono, oRPC,
  commander, fumadocs) integrate with the codebase.
- **Process guides** — `docs/guides/` cover onboarding,
  setup, and operational docs for specific libraries.

This site is a **rendering target** for the content that
benefits from a web surface (onboarding, culture). The
content of every entry here is generated from the source
files in those folders.
