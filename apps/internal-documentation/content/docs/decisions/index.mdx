---
title: Decisions
description: Architecture Decision Records, the load-bearing choices that shape the codebase.
---

Architectural decision records are durable choices, non-negotiable, accepted once and
binding for the codebase. The full set lives at
`docs/engineering/architecture/decisions/`.

Documented requirements (DR) describe the same scope for a
feature that the codebase intends to ship: the load-bearing
choices, the file surface, the env contract, and the manual
smoke steps. A DR is the deliverable of a feature-spec PR; the
implementation PR that follows it inherits the rule.
