The knowledge base is a set of cross-cutting studies of
external libraries the codebase depends on (Better-Auth, Hono, oRPC,
commander, Fumadocs). Each entry describes the lib and the
shape of its integration. The full set lives at
`docs/engineering/architecture/knowledge-base/`.
