documentation as a navigable web surface. The full
architecture decisions, rules, and knowledge-base entries
live as MDX files in version control under
`apps/internal-documentation/content/docs/`; the docs site
reads them directly. {/* vale fix: write-good.Passive */}

## What's elsewhere

The authoritative documentation lives in the monorepo:

- **ADR documents** live in [`decisions/`](decisions/). {/* vale fix: Vale.Spelling */}
- **Rules** are in [`rules/`](rules/).
- **Knowledge base** is in [`knowledge-base/`](knowledge-base/).
- **Process guides** are in [`processes/`](processes/).

This site is a **rendering target** for the content that
benefits from a web surface (new-hire ramp-up, culture).
The content of every entry here derives from the source
files in those folders. {/* vale fix: Vale.Spelling */} {/* vale fix: write-good.Passive */}
