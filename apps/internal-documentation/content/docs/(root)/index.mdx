documentation as a navigable web surface. The full
architecture decisions, rules, and knowledge-base entries
live as Markdown files in version control at
`docs/engineering/architecture/` and are read directly.

## What is elsewhere

The authoritative documentation lives in the monorepo:

- **ADRs** are in `docs/engineering/architecture/decisions/`.
- **Rules** are in `docs/engineering/architecture/rules/`.
- **Knowledge base** is in `docs/engineering/architecture/knowledge-base/`.
- **Process guides** are in `docs/guides/`.

This site is a **rendering target** for the content that
benefits from a web surface (onboarding, culture). The
content of every entry here is generated from the source
files in those folders.
