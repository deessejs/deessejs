# Landing Starter

Landing page starter for SaaS and product marketing sites.

## Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4 + shadcn/ui primitives
- **Animation:** Framer Motion for hero transitions
- **Forms:** React Hook Form + Zod validation

## Getting started

```bash
deessejs init landing-starter
cd landing-starter
pnpm install
pnpm dev
```

## Sections pre-wired

- Hero with product preview
- Feature grid
- Pricing comparison table
- Customer logo wall
- FAQ accordion
- Footer with the same diagonal stripes as the rest of the marketing surfaces
